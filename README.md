# My Singing Monsters Resource Collector

An Android app project designed to help track and collect resources in My Singing Monsters.

## Planned features

- Navigate normal islands and Mirror Islands.
- Collect coins using the in-game Collect All feature.
- Collect ready bakery food.
- Collect diamonds from Mini-Mines.
- Collect diamonds from Maximum Mines on Plant Island and Mirror Plant Island.
- Track resources across the game's islands.
